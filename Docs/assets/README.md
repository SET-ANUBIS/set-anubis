# Documentation assets

The images in this directory are used by the README and the Sphinx manual.
They do not all share the same licence as the SET-ANUBIS source code.

## Project-owned assets

- `set-anubis-logo.png` is the project logo supplied by the SET-ANUBIS
  maintainers.
- `set-anubis-architecture.jpg` and `set-anubis-architecture.png` describe the
  software workflow and ports-and-adapters organisation.

These project-owned assets are distributed with SET-ANUBIS under
GPL-3.0-or-later.

## ANUBIS detector illustration

`anubis-ceiling-concept.png` is a format conversion of a complete page from a
maintainer-supplied PDF. The illustration is reproduced from:

> M. Bauer, O. Brandt, L. Lee and C. Ohm, *ANUBIS: Proposal to search for
> long-lived neutral particles in CERN service shafts*, arXiv:1909.13022.

The source article is distributed under **CC BY-NC-ND 4.0**. The page was
converted from PDF to PNG without cropping or changing the illustrated content.
This file is therefore not relicensed under the repository GPL. Any reuse must
follow the attribution, non-commercial and no-derivatives conditions of the
source licence.
