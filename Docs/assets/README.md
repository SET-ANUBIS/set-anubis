# Documentation assets

The images in this directory are maintained as part of the SET-ANUBIS
documentation.

- `set-anubis-logo.png` is the project logo supplied by the SET-ANUBIS
  maintainers.
- `anubis-detector-concept.jpeg` is the detector-concept illustration used in
  the repository overview and Sphinx manual.
- `set-anubis-architecture.*` illustrates the software workflow and
  ports-and-adapters organisation.

When reusing an image outside the project documentation, cite the SET-ANUBIS
software and the relevant ANUBIS detector publication. Project-owned assets are
distributed under GPL-3.0-or-later together with the repository; material with
an explicit upstream notice remains under that notice.
